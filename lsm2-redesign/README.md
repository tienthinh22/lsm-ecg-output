# LSM-ECG redesign: code

- `lsm_ecg_redesign.ipynb` — the notebook to run (generated by `build_notebook.py`; it embeds `lsm2/` and `tests/`).
- `lsm2/` — the redesign's code (simulator, liquids, levels 1 to 4, gain rule, Maass check, ladder).
- `tests/` — level 1a (closed forms, 1e-9), script mode against (d)'s Brian2 script spike for spike, decision logic.
- `nb/` — the notebook's new cells; the other cells are the replication notebook's, unchanged except where noted
  in `build_notebook.py` (deterministic cuBLAS and algorithms on, Brian2 required).
- `NOTES.md` — where each plan item lives, the numbers the plan does not fix (with reasons), and findings.

Run the tests: `PYTHONPATH=. MAASS_SCRIPT=/path/to/maass2002.py python -m pytest -q tests/`
Rebuild the notebook after editing `lsm2/` or `nb/`: `OLD_NB=/path/to/lsm_ecg_replication.ipynb python build_notebook.py`
